▪ userscripts for github.com and gist.github.com

Small fixes for the parts of GitHub you use every day.

Keyboard shortcuts, copy buttons, raw link copying, a notification badge, a better Gist Discover, and repo management tools. Every feature is a standalone script, and most are bundled into three master scripts so you can install one file and be done.

§ 04

From the README

The parts people ask about most. The full text is in the raw README.

Installation
  • Install a userscript manager: Tampermonkey, Violentmonkey, or ScriptVault.
  • Open the script you want in the repository and click Raw. Your manager offers to install it.
  • Confirm the install, then reload GitHub.

Scripts that copy to your clipboard use the GM_setClipboard grant, so your manager may ask for permission the first time.

GitHub API and tokens

Three scripts talk to the GitHub API: the Repo Wiper, the Last Commit Wiper, and Copy Raw Links. Tokens are stored locally through GM_setValue and never leave your browser except in requests to GitHub.

  • Repo Wiper needs a token with the repo scope, or Contents: write for a fine-grained token. It uses the Git Data API to point the default branch at an empty tree in a single commit. The repo, settings, stars, issues, and prior history stay as they are.
  • Last Commit Wiper needs the same scope and keeps its own token, so it does not share one with the Repo Wiper. It offers four actions: remove only one commit, wipe it and the newer ones, keep it and wipe the newer ones, or revert the latest commit. The three force actions stay locked until you type the branch name.
  • Copy Raw Links works without a token on public repos. It only asks for one when you hit the API rate limit or GitHub refuses a request. A token raises the limit to 5,000 requests an hour.

Configuration

There is no settings UI. Each script keeps its tunables in constants near the top of the file, so you can edit them in your userscript manager.

  • Doomscroll: PRELOAD_MARGIN (default '1200px') and MIN_DELAY_MS (default 400).
  • Spam Filter: add, remove, or edit entries in the RULES array. Each entry is { label, re }.
  • Last Commit Wiper: MAX_REWRITE (default 100) caps how many newer commits one removal will rewrite.
  • Copy Raw Links: CACHE_TTL_MS (10 minutes), AUTO_TIMEOUT (2 minutes), and AUTOGEN_TTL (5 minutes).
Known quirks
  • Do not double up. Install a master script or the matching standalone scripts, not both.
  • The spam filter is heuristic. It will occasionally catch a legitimate gist. Use the Show button in the pill to review what it hid.
  • Pagination and Doomscroll together. Both can run at once, but the page label reflects the page you first loaded.
  • The wipers are destructive. The Repo Wiper force-pushes an empty tree to the default branch. The Last Commit Wiper rewrites branch history, so existing clones and forks keep the old commits. If a commit leaked a secret, rotate the secret. Protected branches can block both.
  • Copy Raw Links limits. Branch names containing a slash may not resolve, and very large repos return a truncated file list.
  • GitHub changes its markup. Selectors may need updating if GitHub redesigns a page.
